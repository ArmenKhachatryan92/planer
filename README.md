# PLANER — стартовый PWA-проект

Это стартовая версия ежедневника. Сейчас задачи сохраняются локально в браузере (localStorage).
Облачная синхронизация Supabase ещё не подключена: `config.js` оставлен пустым намеренно.

## Файлы
- `index.html`, `style.css`, `app.js` — интерфейс и логика простого списка задач.
- `config.js` — сюда на следующем этапе добавим Project URL и Publishable key.
- `supabase_schema.sql` — схема облачной таблицы и RLS-политики.
- `manifest.webmanifest`, `sw.js` — основа PWA.

## Важно
Не добавляйте в публичный репозиторий Supabase Secret key или service_role key.
Текущая версия — прототип, не production-релиз. Перед включением облака нужно реализовать безопасную авторизацию и перенос локальных задач в аккаунт пользователя.
