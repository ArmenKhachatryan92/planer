# PLANER — PWA с Supabase

В этой версии добавлены вход по email/паролю, чтение/создание/изменение/удаление задач в Supabase и однократный перенос локальных задач, если облачный список пользователя пуст.

## Перед запуском
1. В Supabase Authentication → Providers → Email проверьте настройки подтверждения email. Для закрытого личного приложения можно отключить Confirm email, понимая, что регистрация не проверяет владение адресом. Для публичного использования настройте собственный SMTP и оставьте подтверждение включённым.
2. В Supabase Authentication → URL Configuration укажите URL опубликованного сайта в Site URL и Redirect URLs.
3. В `config.js` размещены Project URL и Publishable key. Это публичные клиентские параметры. Никогда не добавляйте Secret key или service_role.
4. Публикуйте файлы в корне GitHub Pages через HTTPS.

## Важные ограничения
- Это рабочий минимальный прототип, не финальный продукт. Требуется тестирование на реальном проекте и устройстве.
- Перед первым входом сделайте резервную копию локальных задач. Автоматический перенос запускается только если облако пользователя пустое.
- Если в облаке уже есть хотя бы одна задача, локальные задачи не переносятся автоматически, чтобы не смешать данные и не создать дубли.
- Уведомления, повторяющиеся задачи, представления календаря неделя/месяц/год и расширенная аналитика пока не реализованы.
